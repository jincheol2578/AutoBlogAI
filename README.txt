📌 프로젝트 소개
이 프로젝트는 블로그 자동화를 위한 시스템입니다.
AI와 크롤링 기술을 활용하여 키워드를 선별하고, 관련 상품 정보를 수집한 뒤 리뷰 초안을 자동으로 작성하는 통합 자동화 도구입니다.
블로그 운영자 또는 마케팅 담당자의 컨텐츠 제작 시간을 단축시키고, 효율적인 키워드 기반 포스팅 생성을 지원합니다.

📋 요구사항 정의
키워드 수집 자동화: 다양한 키워드를 크롤링을 통해 수집

키워드 필터링: 블로그 지수를 기반으로 키워드 유효성 판단

상품 정보 크롤링: 키워드에 해당하는 상품 정보 및 이미지 저장

리뷰 초안 생성: AI를 통해 섹션 기반의 리뷰 콘텐츠 생성

유저 관리: 유저별 데이터 관리 및 접근 권한 분리

✅ 기능 정의
키워드 수집 및 유효성 검증

유효 키워드와 연관된 상품 정보 수집

이미지 파일 별도 테이블 관리

리뷰 초안 자동 생성 및 섹션 기반 저장

유저별 콘텐츠 관리 기능

🏗️ 설계
🔍 요구사항 분석
블로그 콘텐츠 자동 생성의 핵심은 정확한 키워드 선별과 신뢰도 높은 상품 정보 수집

리뷰 생성은 목차별로 관리 가능해야 하고, 유저별로 분리된 데이터 처리 필요
